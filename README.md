# B.Tech Attendance Tracker Web App

Customized for Mahatma Gandhi University (MGU) CSE-A First Semester.

## Features
- **Daily 6 Class Schedule**: Pre-configured with official timetable (Thursday 10-12 free periods).
- **No Faculty Names**: Fully cleaned of lecturer names.
- **Top Percentage Counter**: Real-time overall percentage badge on top.
- **Direct Count Editor**: Adjust total attended/missed classes manually anytime.
- **Smart Bunk Calculator**: Calculates classes to attend or safe bunks to maintain target threshold (default 75%).
- **History & Settings**: Fully editable subjects and persistent storage using browser `localStorage`.

## Host on GitHub Pages
1. Create a public repository on GitHub.
2. Upload all files from this ZIP package (`index.html`, `style.css`, `script.js`, `manifest.json`, `README.md`).
3. Go to **Settings > Pages** in your GitHub repository.
4. Select `main` branch and `/root` folder, then click **Save**.
5. Your live app link will be ready in 1-2 minutes!
